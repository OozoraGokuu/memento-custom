## Dictionaries

Fresh profiles automatically download **Jitendex** for Japanese–English definitions and **JPDB v2.2 Kana** for frequency ranks. JPDB is a frequency dictionary, not a replacement for definitions. Both use the public links below; no account is needed. Jitendex attribution and licensing are available at [jitendex.org](https://jitendex.org/), and JPDB archive provenance is documented in [Kuuuube/yomitan-dictionaries](https://github.com/Kuuuube/yomitan-dictionaries).

Open **Options → Dictionaries → Install default dictionaries** to add missing defaults or retry a failed download. Progress appears here and in the Activity panel. Cancelling clears pending downloads/imports; an import already writing the database finishes safely. Existing dictionaries and their priority are preserved. Remove or disable defaults using the normal dictionary controls; they are not automatically reinstalled on every launch.
